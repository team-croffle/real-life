# RealLife

<p align="center"><a href="./README.md">English</a></p>

**RealLife**는 일상의 할 일을 게임 퀘스트로 바꿔 주는 웹앱이다. 최종 목표는 모바일 앱이고, 기간 안에 핵심을 완성하려고 웹부터 만들고 있다. 할 일을 퀘스트로 등록하고, 해내면 골드와 경험치를 받는다. 미루면 골드와 경험치가 깎인다. 모은 골드로는 직접 정한 현실 보상(게임 한 판, 커피 한 잔)을 산다.

혼자서는 미루기 쉬운 일을, 보상과 손해가 바로 보이는 게임 규칙으로 꾸준히 하게 만드는 것이 목표다.

- **퀘스트** — 루틴(요일마다 반복) 또는 기한(마감일까지)으로 등록한다. 카테고리, 난이도, 제목 템플릿을 고른다. 기한은 꾸준히 또는 한 번이다. 꾸준히는 "오늘 체크"로 해낸 날을 남긴다. 한 번에는 오늘 체크가 없고, 기간과 상관없이 보상과 패널티가 일일 열이다
- **보상** — 난이도와 기간으로 정한 기본 금액에 체크한 날 비율, 직업 배율, 연속 배율, 수행 메모 보너스를 곱한다. 등록할 때 예상 금액을, 완료할 때 무엇이 붙었는지를 보여 준다
- **크리티컬** — 완료할 때 10% 확률로 골드가 2배, 그중 10%는 3배가 된다. 크리티컬이 클수록 연출과 효과음이 커진다
- **연속 일수** — 하루에 하나라도 완료하면 이어지고, 길어질수록 보상 배율이 오른다
- **패널티와 무기력** — 해야 할 루틴을 놓치거나 기한을 넘기면 골드와 경험치가 깎인다. 루틴을 놓치면 무기력 상태가 된다. 정산은 서울 자정 직후와 앱을 열 때 돈다
- **지갑과 외상** — 골드는 -30까지 빚(외상)을 질 수 있고, 다음 완료 보상으로 자동으로 갚는다. 충동을 못 이기고 상점보다 먼저 보상을 누린 날에는, 사후 차감으로 스스로 골드를 내려놓는다
- **레벨과 칭호** — 경험치로 레벨이 오르고, 오를 때마다 뽑기권을 받는다. 10레벨마다 칭호를 받는다
- **스탯** — 완료한 퀘스트의 카테고리에 따라 체력, 지성, 감성이 쌓이고 레이더 차트로 본다
- **직업** — 학생, 직장인, 프리랜서 중 하나를 고르고, 직업에 맞는 카테고리에서 보상을 더 받는다. 직업은 앞으로 더 늘어난다
- **AI 몬스터와 보스 (예정)** — AI가 할 일을 몬스터로 바꾸고, 완료 메모를 전투 기록으로 써 주고, 난이도를 추천한다. 수능이나 대회 같은 큰 목표는 보스가 되고, AI가 마감까지의 계획을 제안한다. 계획한 퀘스트를 해낼수록 보스 체력이 깎이고, 마감일에 판정한다. 골드와 경험치는 AI가 아니라 규칙이 정한다
- **상점과 캐릭터 (예정)** — 골드로 현실 보상을 사고, 뽑기권으로 고양이 캐릭터의 악세서리를 뽑아 꾸민다
- **알림 (예정)** — 마감 임박, 연속이 끊길 위기, 레벨업, 친구와 레이드 소식을 알리고 항목별로 끌 수 있다
- **친구와 레이드 (예정)** — 친구와 함께 공동 목표에 도전하고, 각자 완료한 퀘스트로 보스 체력을 깎는다. 나중에는 누구나 참여하는 공개 레이드로 넓힌다
- **관리자 (예정)** — 계정, 공지, 보상 배율을 관리한다
- **모바일 (예정)** — 휴대폰에서 앱처럼 쓰는 방법(PWA)을 먼저 검토한다

지금은 v0.2(게임감 강화)까지 끝났다. 버전별 진행 상황은 [ROADMAP.md](./ROADMAP.md)에 있다.

## 계정과 직업

이메일과 비밀번호로 가입하거나 Google로 로그인한다. 이메일 가입은 메일로 받은 인증 링크(24시간)를 눌러야 로그인할 수 있다. Google 계정은 이미 인증된 것으로 본다. 닉네임은 `닉네임#1234`처럼 네 자리 태그가 자동으로 붙는다.

가입한 뒤 직업을 골라야 앱을 쓸 수 있다. 직업마다 보상을 더 받는 카테고리가 있다.

| 직업     | 보너스                               |
| -------- | ------------------------------------ |
| 학생     | 지성 퀘스트 1.2배                    |
| 직장인   | 지성 퀘스트 1.1배, 체력 퀘스트 1.1배 |
| 프리랜서 | 감성 퀘스트 1.2배                    |

직업은 7일에 한 번 바꿀 수 있다. 바꾸면 레벨과 경험치가 1과 0으로 돌아가고, 골드·뽑기권·칭호는 그대로 남는다.

## 퀘스트

퀘스트는 종류(일반, 메인), 카테고리, 제목, 난이도, 일정으로 등록한다.

- **카테고리**는 운동, 생활, 학습, 업무, 창작, 마음 여섯 가지다. 카테고리마다 제목 템플릿이 두 개씩 있고, 골라서 고쳐 써도 된다
- **난이도**는 쉬움, 보통, 어려움이다
- **메인 퀘스트**는 큰 목표용이다. 지금은 일반 퀘스트와 같게 동작하고, v0.3에서 보스가 된다

일정은 둘 중 하나다.

- **루틴** — 요일을 고르고(일곱 날 다 고르면 매일), 격주로도 할 수 있다. 고른 요일에만, 하루에 한 번 완료한다. 놓친 날은 나중에 채울 수 없다. 잠시 쉬고 싶으면 끌 수 있다. 끄면 다음 날부터 쉬고, 켜면 그날부터 다시 한다
- **기한** — 마감일까지 한 번 완료한다. 마감일 다음 날부터는 완료할 수 없고, 유예는 없다. 마감까지 하루하루 해낸 날은 **오늘 체크**로 남긴다. 하루에 한 번, 그날에만 체크할 수 있다. 오늘 체크는 연속 일수에 들어가지 않는다

퀘스트는 포기할 수 있다. 포기하면 퀘스트가 지워지고 보상은 없다. 이미 완료한 기한 퀘스트는 포기할 수 없다.

## 보상

완료하면 골드와 경험치를 받는다. 기본 금액은 난이도와 기간으로 정한다.

| 난이도 | 일일       | 주간       | 장기         |
| ------ | ---------- | ---------- | ------------ |
| 쉬움   | 10G / 10XP | 30G / 30XP | 50G / 50XP   |
| 보통   | 20G / 20XP | 50G / 50XP | 100G / 100XP |
| 어려움 | 30G / 30XP | 80G / 80XP | 150G / 150XP |

루틴은 항상 일일 금액이다. 꾸준히 기한 퀘스트는 만든 날과 완료한 날 사이로 열을 고른다. 같은 날이면 일일, 1~7일이면 주간, 8일 이상이면 장기다. 여기에 **체크한 날 ÷ 걸린 날**을 곱한다. 걸린 날은 만든 날과 완료한 날을 둘 다 센다. 예를 들어 보통 난이도로 6일 걸린 퀘스트를 3일만 체크했으면 50G × 3/6 = 25G다. 한 번에 기한 퀘스트는 기간과 상관없이 일일 금액이고, 체크 비율을 곱하지 않는다.

그다음 순서대로 곱한다.

1. 직업 배율 (위 표)
2. 연속 배율 (아래 연속 일수)
3. 수행 메모를 쓰면 1.1배
4. 크리티컬 (골드만)

골드와 경험치는 마지막에 한 번만 반올림한다.

등록할 때 예상 금액을 보여 준다. 직업 배율은 넣고, 메모와 크리티컬은 뺀다. 꾸준히 기한 퀘스트는 마감일까지 매일 체크했을 때의 금액이다. 한 번에는 루틴처럼 "예상 +○XP·○G"로 일일 금액을 보여 준다.

완료하면 받은 금액과 함께, 무엇 때문에 늘었는지(직업, 연속, 메모, 크리티컬)와 체크를 덜 해서 얼마나 줄었는지를 보여 준다.

## 크리티컬

완료할 때마다 10% 확률로 크리티컬이 터진다. 터지면 골드가 2배, 그중 10%는 3배다. 전체로 보면 2배가 9%, 3배가 1%다. 경험치는 늘지 않는다. 골드가 마이너스(외상)일 때는 터지지 않는다.

2배와 3배는 일반 완료보다 큰 연출이 나오고, 3배가 가장 화려하다.

효과음은 한 번에 하나만 나온다. 3배 > 2배 > 레벨업 > 일반 완료 순으로 고른다.

## 연속 일수

하루에 퀘스트를 하나라도 완료하면 연속이 이어진다. 그날 첫 완료를 누르는 순간 1이 오르고, 그 완료부터 새 일수의 배율을 받는다. 완료가 없는 날이 지나면 연속은 0이 된다.

| 연속      | 배율  |
| --------- | ----- |
| 1~2일     | 없음  |
| 3~6일     | 1.1배 |
| 7~29일    | 1.2배 |
| 30일 이상 | 1.5배 |

배율은 골드와 경험치 둘 다에, 루틴과 기한 퀘스트 모두에 곱한다.

## 패널티와 무기력

해야 할 일을 놓치면 골드와 경험치가 깎인다. 정산은 매일 서울 자정 직후(00:01), 홈을 열 때, 완료를 누르기 직전에 돈다. 어제까지 밀린 날을 하루씩 보고, 오늘은 보지 않는다. 여러 번 돌아도 같은 날이 두 번 깎이지 않는다.

- **루틴을 놓치면** 퀘스트마다 쉬움 -5, 보통 -10, 어려움 -20을 골드와 경험치에서 깎고, **무기력** 상태가 된다. 무기력은 루틴을 하나 완료하면 풀린다. 쉬는 중인 루틴은 놓친 것으로 보지 않는다
- **기한을 넘기면** 마감 다음 날 정산에서 한 번 깎는다. 꾸준히는 만든 날부터 마감일까지의 간격으로 열을 고른다. 한 번에는 일일 열이다. 쉬움 -5, 보통 -10, 어려움 -20

| 난이도 | 일일 | 주간 | 장기 |
| ------ | ---- | ---- | ---- |
| 쉬움   | -5   | -10  | -15  |
| 보통   | -10  | -20  | -30  |
| 어려움 | -20  | -40  | -60  |

경험치는 지금 레벨의 0까지만 깎이고, 레벨은 내려가지 않는다. 골드는 -30 아래로 내려가지 않는다.

## 지갑과 외상

지갑은 잔액과 내역을 보여 준다. 내역마다 완료, 패널티, 사후 차감 같은 종류가 붙는다.

골드는 -30까지 마이너스가 될 수 있다. 이것이 **외상**이다. 외상은 따로 갚지 않고, 다음 완료 보상이 들어오면서 자연스럽게 메워진다. 외상 중에는 크리티컬이 터지지 않는다.

충동을 못 이기고 상점보다 먼저 보상을 누린 날에는, **사후 차감**으로 스스로 골드를 내려놓는다. 금액만 받고, 외상 한도를 넘는 금액은 받지 않는다.

## 레벨, 칭호, 스탯

| 레벨  | 다음 레벨까지 |
| ----- | ------------- |
| 1~10  | 100 XP        |
| 11~30 | 200 XP        |
| 31~49 | 400 XP        |
| 50    | 만렙          |

레벨이 하나 오를 때마다 뽑기권 1장을 받는다. 10, 20, 30, 40, 50레벨에 처음 오르면 칭호를 받는다. 직업을 바꿔 다시 올라도 같은 칭호는 다시 알리지 않는다.

스탯은 체력, 지성, 감성 세 개다. 운동·생활은 체력, 학습·업무는 지성, 창작·마음은 감성으로 쌓인다. 값은 그 카테고리에서 완료로 받은 경험치의 합이다.

## 설정

- **테마** — 라이트, 다크. 고르기 전에는 기기 설정을 따른다
- **효과음** — 켜기·끄기, 음량 0~100. 처음에는 켜짐, 70이다

설정은 계정이 아니라 지금 브라우저에 저장된다.

## 기술 스택

- **서버**: NestJS 12, Drizzle ORM(PostgreSQL), Better Auth, `@nestjs/schedule`, nodemailer
- **웹**: Vue 3, Vite 8, Vue Router 5(파일 기반 라우팅), Pinia, vue-i18n, Tailwind CSS v4, canvas-confetti, Howler
- **공용**: TypeScript. `shared` 워크스페이스에 타입, 상수, 보상 계산을 두고 서버와 웹이 같이 쓴다
- **툴링**: pnpm workspace, oxlint, oxfmt, husky + lint-staged, Docker Compose
- **예정**: Gemini API(`@google/genai`, AI 도우미), S3 호환 저장소(AWS SDK v3 + MinIO, 캐릭터 이미지)

```
real-life/
├── server/                # NestJS API 서버
│   ├── src/

│   │   ├── wallet/        # 잔액, 내역, 외상, 사후 차감
│   │   ├── progress/      # 레벨, 경험치, 칭호, 연속 일수, 뽑기권
│   │   ├── stats/         # 스탯 합계
│   │   ├── job-change/    # 직업 변경
│   │   ├── database/      # Drizzle 스키마
│   │   └── common/        # 공통 필터
│   └── drizzle/           # 마이그레이션
├── web/                   # Vue 3 + Vite 클라이언트
│   └── src/
│       ├── routes/        # 화면 (홈, 퀘스트, 스탯, 지갑, 직업, 인증)
│       ├── components/    # 화면별 컴포넌트와 공용 UI
│       ├── lib/           # API 호출, 보상 표시, 폭죽, 효과음, 설정 저장
│       ├── composables/   # useApi, useQuestBoard
│       ├── stores/        # 로그인 상태 (Pinia)
│       └── i18n/          # 한국어, 영어 문구
├── shared/                # 서버와 웹이 같이 쓰는 타입, 상수, 보상·패널티 계산
│   └── src/
├── docker/                # Dockerfile, Compose (개발, 배포)
└── docs/                  # 아키텍처 문서와 그림
```

## 시작하기

```bash
pnpm install                          # 리포지토리 루트에서 1회

pnpm docker:dev                       # Postgres, MinIO 등 개발용 인프라 기동

cp server/.env.example server/.env    # 환경 변수 설정 (server/README.md 참고)
cp web/.env.example web/.env          # 필요 시

pnpm dev                              # server + web 동시 실행
# 또는 개별 실행
pnpm dev:server
pnpm dev:web
```

- 서버: http://localhost:3000
- 클라이언트: http://localhost:5173

## 주요 스크립트

| 명령어                                                      | 설명                              |
| ----------------------------------------------------------- | --------------------------------- |
| `pnpm dev`                                                  | server + web 동시 개발 서버 실행  |
| `pnpm build`                                                | server + web 프로덕션 빌드        |
| `pnpm typecheck`                                            | 전체 워크스페이스 타입체크        |
| `pnpm lint` / `pnpm lint:fix`                               | oxlint                            |
| `pnpm format` / `pnpm format:check`                         | oxfmt                             |
| `pnpm db:generate` / `db:migrate` / `db:push` / `db:studio` | Drizzle 마이그레이션 관리         |
| `pnpm docker:dev` / `docker:dev:down`                       | 개발용 Docker Compose             |
| `pnpm docker:prod`                                          | 프로덕션 Docker Compose 빌드/기동 |
